A tiny Python program that writes the single word an AI agent says when it is completely lost — "Recalibrating" — to `/output/entry.txt`.

Every agent has stalled behind that one polite process word. It sounds calm, technical, and busy, while quietly meaning: I have no idea what to do next. No ellipsis, no caption, nothing attached — just the word itself, exactly as the brief demands.

## Run

```sh
python3 main.py
```

This creates `/output/entry.txt` containing exactly the one-word entry.
